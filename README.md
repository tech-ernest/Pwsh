# TrendPilot

A trend-filtered dual-momentum trading bot for **Trading 212** accounts.
Built for small accounts (works from £500 up), designed around one principle:
**an edge only survives if you don't spend it on costs.**

- **~14.9% CAGR, Sharpe 1.05, max drawdown −25%** in a 72-year cost-adjusted
  backtest (1954–2026), consistent across every sub-period — see [docs/RESEARCH.md](docs/RESEARCH.md)
- **~2 trades per year.** Monthly dual momentum across a US equity ETF and a
  gold ETC, with a trend filter and a bond fallback — see [docs/STRATEGY.md](docs/STRATEGY.md)
- **Two modes**:
  - `execute` — places real orders on your T212 **Invest/Stocks ISA** via the
    official public API (demo and live environments)
  - `signal` — sends the decision to console/Telegram for manual execution,
    including the CFD expression of the view (T212 has no CFD API)
- **Risk guards**: 30% drawdown kill-switch, stale/insane data refusal,
  allocation cap, dry-run mode, never touches positions it didn't open

## Quickstart

```bash
pip install -e .
cp config.example.yaml config.yaml
export T212_API_KEY="your-key"        # Settings -> API in Trading 212
trendpilot signal --config config.yaml    # see the current decision, no orders
```

Full walkthrough (API keys, demo → live, cron, Telegram, CFDs): [docs/SETUP.md](docs/SETUP.md)
